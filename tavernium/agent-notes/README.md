# agent-notes/ — 排查报告投放区

这个目录是给**接手排查的 agent** 用的。你不需要改代码，只要在这里留一份报告。

## 怎么用

1. 复制 `000-template.md`，重命名为 `<你的名字或角色>-<YYYYMMDD>.md`
   - 例：`security-reviewer-20261024.md`
   - 已有同名文件就加后缀 `-2`
2. 按模板填完，**每条发现必须有 `文件:行号`**
3. 主 agent 会读这个目录，并在同目录下回一份 `<同名>-review.md`，逐条给结论

## 硬性要求

- 不要写真实服务器地址 / IP / 账号 / 密码，用 `<UPD_HOST>` 这类占位符
- 拿不准的放「需要主 agent 复核的点」，不要混进「发现清单」
- 只写报告，不改源码（除非主 agent 明确授权）
- 不要建议改签名配置、applicationId、下载目录名——这三项是用户已决策项

## 文件说明

| 文件 | 用途 |
|---|---|
| `000-template.md` | 报告模板，复制它 |
| `*-review.md` | 主 agent 的回复，不要手改 |
