Tavernium 使用指引

离线版 · 不联网也能看 · 按返回键关闭本页

打开菜单

任意页面按系统返回键，或从屏幕左/右边缘向内滑，菜单直接弹出。网页后退在菜单第一项「返回上一级」。

Tavernium 没有独立的设置页，服务器、挂机、通知、更新、日志都在这个菜单里。

常用功能

修改服务器主菜单「修改服务器地址」。局域网可用 http://192.168.x.x:8000，公网需 https://。
后台保活保持「后台暂停网页」为关；再到系统设置允许 Tavernium 后台活动。
挂机防烧屏主菜单「挂机模式」，进入黑屏省电状态，触摸或上滑唤醒。
回复通知主菜单「回复完成通知」。首次开启需允许系统通知权限。
检查更新主菜单「检查更新」。正式版与调试版是独立应用，可同时安装。

反馈问题：导出日志

  1. 打开主菜单，点「调试与诊断…」。
  2. 把「性能监控」和「详细日志」都打开，状态显示“开”。
  3. 彻底退出应用再重开，按原来的步骤复现问题，例如打开某个角色、发送图片、切换页面。
  4. 回到菜单 → 调试与诊断 → 导出性能日志。文件通常在 下载/SillyTavern/，名字以 tavernium-perf- 开头。
把日志文件和以下信息一起发：手机型号、系统版本、Android System WebView 版本、问题发生时间和现象。

图片显示异常

只有图片错位、尺寸不对：多半是网页 CSS 与旧内核不兼容。

图片空白但文字正常：检查图片是否为 http://（被 HTTPS 页面拦截）、AVIF/HEIC 格式，或图床防盗链。

按钮和脚本也失效：可能 WebView 版本过低。设置 → 应用 → 显示系统应用 → Android System WebView 查看版本，建议 Chromium 100 以上。

常见问题

切后台回来就重载？确认「后台暂停网页」为关，并在系统电池设置里允许后台活动。部分机型仍会深度冻结，属系统限制。

通知不响？检查系统通知权限、电池优化白名单，以及酒馆页面是否仍在运行。

返回键没弹菜单？正在全屏播放视频时，第一次返回只退出全屏，再按一次即可。

日志名是 tavernkeep-perf-？2.0.1 及更早版本使用旧前缀，以实际导出文件为准。
